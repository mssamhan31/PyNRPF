2. Background And Datasets

Alpha gives controlled ground truth, while Beta tests the real oracle problem

Dataset Alpha

Alpha contains observed negative net-load readings. For sign-error modelling, negative readings can be converted to positive wrong-sign readings by taking their absolute value, while true RPF windows remain known.

3. Goal And Evaluation

The optimisation target is day F1, with confidence used to reduce review workload

The practical aim is to minimise manual checking, not to claim manual checking can be removed completely. The model should rank site-days so high-confidence decisions can be accepted quickly and ambiguous days remain in a smaller review queue.

Primary model-selection metric: Beta leave-one-site-out sure-only day-level F1. Beta all-days, interval F1, window IoU, energy F1, and energy IoU are secondary checks.

Day flag

Does this day contain an RPF sign-error window?

Start/end window

One predicted RPF interval per positive day.

Confidence or margin

How far the prediction sits from the selected threshold.

4. Method Overview

m9_pbm scores whether sign correction makes demand physically plausible

m9_pbm searches candidate windows during daytime and asks whether flipping the sign creates a more plausible underlying demand curve.

Let \(\ S(t)\ \) be solar generation and \(\ y(t)\ \) be recorded net load.

Outside candidate window \(\ W\ \): \(\ U(t)=S(t)+y(t)\ \)
Inside \(\ W\ \): compare \(\ U_{\mathrm{no}}(t)=S(t)+y(t)\ \) with \(\ U_{\mathrm{corr}}(t)=S(t)-y(t)\ \).
Real reviewed Beta RPF day. The corrected underlying demand curve is computed as \(S(t)-y(t)\) inside the window and compared against \(S(t)+y(t)\).
5. Feature 1: Bridge

Bridge is the strongest single signal because true windows repair a demand gap

The bridge feature measures whether corrected demand joins more smoothly from the left side of the candidate window to the right side.

\(B(W)=E_{\mathrm{bridge}}(U_{\mathrm{no}},W)-E_{\mathrm{bridge}}(U_{\mathrm{corr}},W)\)
  • Large positive B(W) means the corrected curve bridges the shoulders better.
  • It was the strongest separator in Beta sure-only days.

6. Feature 2: Roughness

Roughness improves window quality by rewarding smoother corrected demand

Roughness uses total variation or mean absolute changes in the reconstructed demand curve. Corrected demand should usually be less jumpy than the uncorrected interpretation.

\(TV(U,W)=\sum_{t \in W^+}|U(t)-U(t-\Delta t)|\)
\(R(W)=TV(U_{\mathrm{no}},W)-TV(U_{\mathrm{corr}},W)\)
  • Roughness is a window-quality feature, not only a day detector.
  • The best grid result increased roughness weight to 1.5.

7. Feature 3: N-height

N-height captures the raw net-load bounce that many false positives lack

True RPF days often show raw net load rising into an N-shaped bounce inside the wrong-sign window. Many false positives have a much weaker bounce.

\(H_N(W)=\frac{\max(y_W)-\max(y_{\mathrm{left}},y_{\mathrm{right}})}{\mathrm{scale}_{\mathrm{site/day}}}\)
  • It tests the visual FP/FN hypothesis directly.
  • It reduces weak low-bounce false windows.

8. Other Features

The remaining features act as interpretable guardrails around the core physics score

Window plausibility guards

Duration

Encodes that plausible RPF windows are not usually extremely short.

\(D(W)=\min(1,\mathrm{duration}(W)/1.5\mathrm{h})\)

Solar strength

Penalises weak-solar candidates.

\(S_{\mathrm{ratio}}(W)=p95(S_W)/p95_{\mathrm{site}}(S)\)

Solar peak alignment

Keeps the search aligned with the physical driver.

\(A(W)=1-\mathrm{dist}(\mathrm{mid}(W),\mathrm{peak}_S)/3.5\mathrm{h}\)

Site comparability guards

Site-centered score

Subtracts a site baseline using unlabelled site score distribution.

\(C_{\mathrm{site}}(d)=\mathrm{core}(d)-\mathrm{median}_{\mathrm{site}}(\mathrm{core})\)

Site rank score

Uses within-site percentile rank to compare days within a site.

\(R_{\mathrm{site}}(d)=\mathrm{percentile\_rank}_{\mathrm{site}}(\mathrm{core}(d))\)

Slope continuity

A secondary guard for jumpy windows, not a strong positive discriminator.

\(SC(W)=\mathrm{slope\_jump}(U_{\mathrm{no}})-\mathrm{slope\_jump}(U_{\mathrm{corr}})\)
