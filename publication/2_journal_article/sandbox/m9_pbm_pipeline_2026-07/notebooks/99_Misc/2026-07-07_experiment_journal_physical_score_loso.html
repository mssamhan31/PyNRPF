Experiment Journal: Fast Physical-Score LOSO Model Development

Date: 2026-07-07 | Folder: publication/2_journal_article/notebooks/99_Misc

Executive Summary

This report summarises the fast C0-C9 experiment ladder for the interpretable physical-score RPF sign-error detector. The goal was to find a simple, defensible day-level model that works well on the final manually reviewed Dataset Beta labels, while keeping computation fast and avoiding broad black-box model development.

Current best model-development result: R1_beta_loso / M9_drop_site_rank, meaning the physical score is tuned with Beta leave-one-site-out validation and the F9 site-rank component is removed. On Beta sure-only days it achieves precision 0.8875, recall 0.8838, and F1 0.8857.

The strongest practical insight is not just the all-days F1. The model also localises windows well: on Beta sure-only true-positive days the median window IoU is 0.9167 and the median start/end boundary error is 15 minutes. Confidence triage is highly promising: if only the highest-confidence 80% of Beta sure-only days are auto-accepted, the current best model reaches F1 0.9898 with 5 mistakes, while leaving 466 days for manual review.

Method

Data Used

The experiments use the refreshed final journal datasets. Dataset Beta was regenerated from the latest final oracle review labels before the experiment ladder was continued. Final Beta contains 280,800 interval rows, 2,928 site-days, 634 RPF site-days, and confidence labels with 2,330 sure days and 598 unsure days.

Physical Score Components

Each site-day is scanned using dense daytime candidate windows. Each selected window receives nine interpretable components:

IDComponentPurpose
F1bridge_improvementCorrected underlying demand should bridge more smoothly between window boundaries.
F2roughness_improvementCorrected demand should have lower roughness or total variation.
F3slope_continuity_improvementCorrected demand should reduce boundary slope jumps.
F4duration_plausibilityLonger plausible RPF windows are favoured up to a saturation point.
F5n_height_ratioCaptures the net-load bounce shape expected in sign-error RPF.
F6solar_strength_ratioReduces weak-solar false positives.
F7solar_peak_alignmentFavours windows centred near the solar peak.
F8site_centered_core_scoreSite-median adjustment using unlabelled site score distribution.
F9site_rank_core_scoreWithin-site percentile rank of the core score.

Regimes And Variants

The main regimes were:

  • R1_beta_loso: tune threshold on the other seven Beta sites, sure days only; test on the held-out Beta site.
  • R2_beta_loso_plus_alpha: tune on all Alpha plus the other seven Beta sites, with dataset-balanced threshold selection.
  • R3_alpha_only_to_beta: tune on Alpha only; evaluate on all Beta sites.

Manual variants include all equal weights and drop-one ablations. The current winning variant, M9_drop_site_rank, is the all-equal score with the F9 site-rank component removed. A lightweight logistic regression variant was also tested, but it did not beat the best manual score.

This is a model-development experiment, not yet final publication validation. Beta labels were used for model selection in R1/R2, so future paper framing should clearly distinguish model development from final locked validation.

4. Logistic Regression Did Not Beat The Manual Score

Logistic regression on the nine components was useful as a check, but it did not outperform the best manual score. R1 logistic reached Beta sure-only F1 0.8796, below R1 M9 at 0.8857. R2 logistic became very recall-heavy, reaching recall 0.9896 but precision only 0.6525. This suggests that the current low-parameter manual score is still the better journal-facing candidate.

6. Metric Selection For Model Optimisation

Several useful metrics are now available: day F1, interval F1, window IoU, correction-energy F1, correction-energy IoU, and confidence-coverage F1. The recommended primary model-selection metric remains Beta LOSO sure-only day-level F1.

The reason is practical: if the day flag is wrong, the window quality is irrelevant. Day F1 is also easier to explain, robust to small boundary disagreements, and aligned with the manual review workflow. The other metrics should be treated as required secondary checks:

  • Interval F1 confirms that the output interval labels are usable.
  • TP-day IoU confirms that predicted windows overlap manual windows.
  • Correction-energy F1/IoU confirms that the model captures the high-impact MWh correction.
  • Confidence-coverage F1 confirms whether the model can support triage and partial automation.

7. Confidence Triage Is The Strongest Production Insight

The confidence score is defined as the distance between the selected score and the selected threshold. High-confidence days are those farthest from the decision boundary. For R1 / M9_drop_site_rank, confidence-based triage can auto-accept a large fraction of days with much higher performance than the full 100% set.

Conclusion

The fast experiment ladder has produced a clear model-development direction. A simple physical-score method, tuned under Beta leave-one-site-out validation, performs better than Alpha-only transfer and better than the lightweight logistic regression check. The best pooled result is R1_beta_loso / M9_drop_site_rank, with Beta sure-only F1 0.8857 and Beta all-days F1 0.8028.

The method is not yet a fully automated, no-manual-checking production detector. However, the confidence triage results are strong enough to support a practical workflow: auto-accept easy high-confidence days and concentrate human review on the uncertain residual set.

The interval/window evaluation strengthens the result. The current best model achieves Beta sure-only interval F1 0.8725, TP-day median IoU 0.9167, and correction-energy F1 0.9392. This means the detector is not merely finding correct days; it is also finding useful correction windows and recovering most of the MWh correction impact.

For the journal paper, the strongest story is therefore not "perfect replacement of manual review". The stronger and more defensible story is: interpretable physics-based scoring can detect many RPF sign-error days with strong performance, localise the correction windows well, recover most correction energy, and use confidence triage to substantially reduce manual review burden.

Next Recommendation

  • Freeze R1/R2 M9_drop_site_rank as the current candidate method family for write-up and deeper error analysis.
  • Inspect the 20% low-confidence bucket from the 80% triage setting. This is where future model improvements should focus.
  • Produce example plots for the remaining false positives and false negatives under R1 / M9_drop_site_rank, especially Beta A, Beta D, Beta H, and ambiguous unsure days.
  • Decide paper framing: either use R1 as the clean real-data generalisation result, or use R2 if site-balance is judged more important than the tiny pooled F1 difference.
  • Use Beta LOSO sure-only day F1 as the primary optimisation metric, with interval F1, TP-day IoU, correction-energy F1/IoU, and confidence-coverage F1 as secondary acceptance checks.
